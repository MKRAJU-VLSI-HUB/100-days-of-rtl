100 Days of RTL Design: done. 100 Verilog designs, 100 passing testbenches.

I started this challenge to get my digital design basics really solid. My rule was simple: a design only counts once a self-checking testbench says PASS in Vivado. No judging waveforms by eye.

How it went:
- Days 1-30: gates, adders (ripple, carry look-ahead, carry select, BCD), muxes, decoders, a barrel shifter, an ALU, Vedic and array multipliers, Hamming error correction
- Days 31-60: flip-flops, shift registers, counters, clock dividers (including a true 50% duty divide-by-3), debouncers, clock domain crossing, state machines like a vending machine and a traffic light
- Days 61-80: register file, RAMs, sync and async FIFOs, a CAM, a March C- memory self-test, Booth multiplier, divider, square root, MAC, FIR, CRC-8, arbiters
- Days 81-100: digital clock, stopwatch, watchdog, UART, SPI, APB, a skid buffer, an elevator controller, a systolic array, CORDIC, and an 8-bit CPU that runs a Fibonacci program as the finale

Where the input space was small enough, I tested every input. All 65,536 signed pairs for the Booth multiplier, every dividend/divisor pair for the divider, all 65,536 inputs for the square root.

What surprised me most was going back to my older lab exercises with proper testbenches. They turned up real bugs: a FIFO that could only hold 15 of its 16 entries, an FSM that drove one signal from two always blocks, a register file that only cleared one register on reset, and an LCM block that could never be synthesised.

A few Verilog lessons I won't forget:
- Checking an output in the same time step its input changes gives you the old value
- An assign that calls a function only wakes up when the function's arguments change
- One unsigned operand inside ? : makes the whole expression unsigned
- CORDIC accuracy went from about 9 LSB to about 1 LSB just by adding guard bits and rounding
